Stratus Red Team: A "purple teaming" tool by Datadog that allows security engineers to emulate specific, controlled offensive cloud attacks (like IAM credential theft or Lambda abuse) to validate detection and monitoring systems.

Grimoire : Grimoire is a "REPL for detection engineering" that allows you to generate datasets of cloud audit logs for common attack techniques. It currently supports AWS.

Pacu: An open-source exploitation framework designed for AWS security testing, featuring modules for enumeration, permission auditing, privilege escalation, and data exfiltration.

ScoutSuite: An open-source multi-cloud auditing tool (supporting AWS, Azure, and GCP) that assesses security posture and maps out configuration risks.Microburst: A collection of PowerShell scripts and tools tailored for Azure security assessment, discovery, and post-exploitation.

Prowler: An open-source security tool for AWS, Azure, and GCP that performs configuration reviews, best-practice checks, and compliance alignments (CIS, GDPR, HIPAA).

CloudFox: An automated reconnaissance and attack-path discovery tool by Bishop Fox that helps operators navigate cloud environments and find privilege escalation paths.

COBRA (Cloud Offensive Breach and Risk Assessment): An open-source tool by Palo Alto Networks built to simulate complex multi-cloud attack chains, including lateral movement and insider threats.
